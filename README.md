# Python_Alarma
Programacion en Python de una simulación de alarma con Raspberry y protoboard.

Creamos un código Python que utilizaremos en una raspberry pi. A la raspberry conectamos un sensor de presencia, dos leds y un buzzer. Entre los tres y en conjunto con el monitor de la raspberry, simularán un sistema de alarma con cambio de contraseña.

El código se ha creado en un loop constante para que una vez introducida la contraseña vuelva a reiniciarse y espera la detección de movimiento.
